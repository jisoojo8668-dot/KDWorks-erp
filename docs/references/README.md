# 참고 자료 (references)

기획·설계의 정답 데이터가 되는 실제 업무 파일(엑셀, PDF, 이미지)을 둡니다. 원본 그대로 올립니다.

## 폴더

| 폴더 | 넣는 것 |
|------|--------|
| `prj/` | 실행예산 엑셀, 기성청구서 엑셀, 작업일보 양식 |
| `hr/` | 직원 급여 엑셀, 4대보험 고지서 양식, 근로계약서 양식 |
| `acc/` | 은행 대량이체 파일 양식, 회계 프로그램 내보내기 양식 |
| `mat/` | 자재 품목 목록(품명·규격·단위·분류), 자재 단가표, 창고 재고 목록 |
| `sal/` | 견적서·내역서 양식, 발주처 견적 양식 샘플 |
