## 이번까지 확정된 주요 결정

- 현장 손익이 최우선. 모든 원가는 `acc.RecordCost` 로만 원가 원장에 기록, 원장은 추가만(수정 금지).
- 일용직: 개인 계좌 지급, 현장소장이 매일 공수(1.0/0.5/1.5) 입력, 직종 일당 + 개인 예외, 지급그룹별 주기, 1인 1일 공종 1개, 회사 부담 보험·퇴직공제까지 현장 원가, 외국인 있음, 마감 때 본사 결재.
- 직원(50~100명): **지금 엑셀로 급여 계산 + 4대보험 고지서 금액 기입** → ERP에서 급여 계산 전체로 대체(더존 연계안 폐기). 보험은 자동 계산 + 고지서 대조, 포괄임금, DB형/퇴직금, 회계연도 연차, 모바일 출퇴근(위치), 연 1회 평가(부서장→대표), 급여·평가는 대표+인사만 열람.
