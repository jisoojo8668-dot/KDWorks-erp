# AI 개발 하네스 (KD기공 ERP)

AI 코딩 에이전트가 이 저장소에서 규칙을 지키며 일하도록 만든 장치 모음입니다.
원칙은 **"규칙은 문서로 알려주고, 중요한 규칙은 스크립트로 강제하고, 완료는 검사 통과로 판단한다"** 입니다.

## 구성

| 층 | 파일 | 역할 |
|----|------|------|
| 1. 안내 | `CLAUDE.md` | 프로젝트 요약, 구조, 필수 규칙, 작업 방식, 도메인 용어. AI가 매 작업마다 읽음 |
| 2. 규칙 검사 | `scripts/check-arch.sh` | 모듈 경계, 원가원장 쓰기 위치, 금액 float 금지, 커밋된 마이그레이션 수정, 비밀값 커밋 검사 |
| 3. 완료 기준 | `Makefile` (`make check`) | gofmt → go vet → golangci-lint → 테스트(-race) → 아키텍처 → 프론트 검사 |
| 4. 실시간 가드 | `.claude/hooks/` (원본: `harness/claude/`) | 수정 전 차단 / 수정 후 자동 포맷·검사 / 종료 전 `make check` 강제 |
| 5. 커밋 가드 | `harness/git/pre-commit` | 사람이 커밋할 때도 포맷·아키텍처 검사 |
| 6. 린트 | `.golangci.yml` | errcheck, gosec, sql 리소스 누수 검사 등 |

## 훅 동작

| 시점 | 스크립트 | 동작 |
|------|---------|------|
| AI가 파일 수정 **전** | `pre-edit-guard.sh` | `.env`·키 파일, 커밋된 마이그레이션, sqlc 생성 코드, 하네스 파일 수정을 차단 |
| AI가 파일 수정 **후** | `post-edit-format.sh` | Go/TS 자동 포맷, 규칙 위반 시 즉시 AI에게 오류 전달 → AI가 스스로 수정 |
| AI가 작업 **종료** 시 | `stop-verify.sh` | `make check` 실행, 실패하면 종료를 막고 오류를 돌려줌 |

## 설치

```bash
cd ~/GoProjects/KdWorks/KD기공
git init                     # 아직 안 했다면
bash harness/install.sh      # .claude/settings.json, 훅, pre-commit 설치
brew install go jq golangci-lint sqlc goose
go install golang.org/x/tools/cmd/goimports@latest
```

> `.claude/` 폴더는 보안상 AI가 직접 만들 수 없어 `harness/` 에 원본을 두고 설치 스크립트로 복사합니다.
> 하네스 규칙을 바꿀 때는 `harness/` 원본을 사람이 고치고 `install.sh` 를 다시 실행하세요.

## 규칙을 늘려가는 방법

AI가 같은 실수를 두 번 하면 그 실수를 하네스에 추가합니다.
1. 사소한 것 → `CLAUDE.md` 에 한 줄 규칙 추가
2. 돈·데이터에 영향 → `check-arch.sh` 에 자동 검사 추가 (예: 권한 필터 누락, 감사로그 누락)
3. 계산 로직 → 기대값 테스트(골든 테스트) 추가: 실제 현장의 기성·원가 엑셀을 정답 데이터로 사용
